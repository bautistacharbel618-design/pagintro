Atributos de FORM

Tabla de atributos de <form>

Atributo ¿Para qué se usa? Ejemplo en HTML
action Indica a dónde se mandan los datos. <form action="procesar.php">
method Indica cómo se mandan los datos. <form method="post">
target Indica dónde se abre el resultado. <form target="_blank">
autocomplete Permite que el navegador recuerde o complete datos. <form autocomplete="on">
novalidate Hace que el navegador no revise los datos automáticamente. <form novalidate>
enctype Indica cómo se preparan los datos para enviarlos. <form enctype="multipart/form-data">
